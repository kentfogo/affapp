# Mental Victory Practice - App Context

## Project Overview

- **Name:** Mental Victory Practice
- **Purpose:** Mobile affirmations app that plays personalized affirmations at intervals during movement sessions (walking, running, cycling, yoga, etc.)
- **Platform:** React Native (Expo) - iOS, Android, Web
- **Target Users:** People seeking positive reinforcement during physical activities

## KEY USER FLOWS
================================================================================

FLOW 1: FIRST-TIME USER
─────────────────────────
1. Open App
2. Login Screen → Choose Guest/Email
3. Onboarding (4 steps)
4. Auto-navigate to Affirmations Screen
5. Select 5-10 affirmations (swipe cards)
6. Navigate to Home
7. Tap "Ready to Start"
8. Active Session (affirmations play at intervals)
9. Hold to Stop
10. View Summary
11. Return to Home

FLOW 2: RETURNING USER (QUICK SESSION)
────────────────────────────────────────
1. Open App → Auto-login
2. Home Screen
3. Tap "Ready to Start"
4. Active Session
5. Hold to Stop
6. View Summary
7. Return to Home

FLOW 3: CHANGE AFFIRMATIONS
─────────────────────────────
1. Home Screen
2. Tap "Affirmations" tab
3. Swipe through cards
4. Accept/Reject affirmations
5. Done (5-10 selected)
6. Return to Home

FLOW 4: ADJUST SETTINGS
─────────────────────────
1. Home Screen
2. Tap "Settings" tab
3. Toggle Time/Distance intervals
4. Select interval duration (30s, 60s, etc.) or distance (0.5mi, 1mi, etc.)
5. Change distance units (miles/km)
6. Return to Home

FLOW 5: RESET ONBOARDING
──────────────────────────
1. Settings Tab
2. Tap "Reset Onboarding"
3. Confirm
4. Navigate back to Onboarding flow
5. Complete all steps
6. Navigate to Affirmations (if none selected) or Home

FLOW 6: PASSWORD RESET
────────────────────────
1. Login Screen
2. Tap "Forgot Password?"
3. Enter email (iOS: Alert.prompt, Android: Modal)
4. Receive reset email
5. Open email, click link
6. Reset password via Firebase
7. Return to app and login

## DATA FLOWS
================================================================================

SESSION DATA FLOW:
──────────────────
1. User selects affirmations
   → storageService.saveSelectedAffirmations()
   → sessionStore.setSelectedAffirmations()

2. User configures session settings
   → settings.tsx
   → storageService.saveSessionSettings()
   → sessionStore.setSessionSettings()

3. User starts session
   → session.tsx
   → sessionStore.startSession()
   → locationService.startTracking() (if distance-based)
   → audioService.initialize()

4. Session runs
   → Timer increments every second
   → Location updates trigger distance calculation
   → Interval reached → audioService.playAffirmation()
   → Affirmation counter increments
   → sessionStore.updateSessionState()

5. User stops session
   → sessionStore.endSession()
   → storageService.saveSessionLog() (SQLite)
   → locationService.stopTracking()
   → Navigate to summary.tsx

6. View summary
   → Display session stats
   → Option to return home

AUTHENTICATION DATA FLOW:
──────────────────────────
1. User enters credentials
   → login.tsx

2. Submit to Firebase
   → authStore.signInWithEmail() / signUpWithEmail()
   → Firebase Auth API

3. Success
   → authStore.setUser(user)
   → onAuthStateChanged listener updates store
   → Navigate to onboarding or home

4. Error
   → Parse error code
   → Display user-friendly message

5. Password reset
   → authStore.resetPassword(email)
   → Firebase sends reset email
   → User clicks link in email
   → Firebase handles reset
   → User returns to app to login

ONBOARDING DATA FLOW:
──────────────────────
1. User completes onboarding steps
   → onboarding.tsx
   → onboardingStore.saveOnboarding()

2. Save to storage
   → storageService.saveOnboarding()
   → AsyncStorage persists data

3. Check affirmations
   → sessionStore.selectedAffirmations
   → storageService.getSelectedAffirmations()

4. Navigate based on affirmation status
   → No affirmations: /(tabs)/affirmations
   → Has affirmations: /(tabs)/home
